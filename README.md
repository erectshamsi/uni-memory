# حافظه سازمانی دانشگاه — نسخه اصلاحی اتصال منابع و جست‌وجو

این نسخه بر پایه سورس ارسالی شما اصلاح شده است. هدف اصلی اصلاح این است که **پنل مدیریت و موتور پاسخ‌گویی دقیقاً از یک منبع ذخیره‌سازی مشترک استفاده کنند**.

## رفع اشکال‌های اصلی

1. در نسخه قبلی، `api/documents.js` اسناد را روی فایل‌سیستم موقت Vercel می‌نوشت، اما `api/chat.js` در صورت وجود `GITHUB_TOKEN` فایل `data/documents.json` را از GitHub می‌خواند. بنابراین پنل می‌توانست پیام «ذخیره شد» بدهد، درحالی‌که دستیار نسخه دیگری از اسناد را می‌خواند.
2. در نسخه قبلی پنل مقدار اعتبار `current` ذخیره می‌کرد، ولی موتور پاسخ‌گویی فقط مقدار `valid` را معتبر تلقی می‌کرد؛ در نتیجه اسناد جاری نیز ممکن بود به‌اشتباه به کارشناس ارجاع شوند.
3. جست‌وجوی فارسی اکنون «ي/ی»، «ك/ک»، نیم‌فاصله و اعراب را یکسان‌سازی می‌کند و عنوان و متن سند را با هم می‌سنجد.
4. ذخیره موفق فقط پس از ثبت موفق فایل در GitHub اعلام می‌شود؛ اگر اتصال ذخیره‌سازی مشکل داشته باشد، خطای روشن برمی‌گردد و پیام موفقیت کاذب نمایش داده نمی‌شود.
5. API مدیریت منابع و تنظیم وب‌هوک بله با کلید مدیریت محافظت شده‌اند. در نسخه قبلی این APIها بدون احراز هویت در دسترس بودند.

## متغیرهای لازم در Vercel

در مسیر **Project → Settings → Environment Variables** این متغیرها را تعریف کنید:

| نام متغیر | مقدار |
|---|---|
| `GITHUB_TOKEN` | توکن GitHub با مجوز Contents: Read and write برای همین مخزن |
| `GITHUB_REPO` | نام مخزن با قالب `owner/repository` |
| `GITHUB_BRANCH` | نام شاخه؛ معمولاً `main` |
| `ADMIN_API_KEY` | یک رمز مدیریتی قوی و جدید که خودتان تولید می‌کنید |
| `APP_URL` | نشانی نهایی سایت با HTTPS، بدون اسلش پایانی |
| `OPENROUTER_API_KEY` | اختیاری؛ کلید سرویس مدل زبانی |
| `OPENROUTER_MODEL` | اختیاری؛ شناسه مدل مورد استفاده در OpenRouter |
| `BALE_BOT_TOKEN` | اختیاری؛ توکن ربات بله |
| `BALE_WEBHOOK_SECRET` | اختیاری؛ رمز محرمانه وب‌هوک بله |

**مهم:** هیچ‌یک از توکن‌ها یا رمزها را داخل فایل‌های پروژه، HTML، GitHub یا پیام عمومی قرار ندهید. فقط در Environment Variables خود Vercel تنظیم کنید. پس از تغییر متغیرها، یک Redeploy لازم است.

توکن GitHub باید فقط به مخزن همین پروژه دسترسی داشته باشد و مجوز **Contents: Read and write** داشته باشد. برنامه فایل `data/documents.json` را در شاخه مشخص‌شده می‌خواند و به‌روزرسانی می‌کند.

## استفاده از پنل مدیر

1. نشانی پنل را باز کنید: `/admin-ec-9842`
2. همان مقداری را که برای `ADMIN_API_KEY` در Vercel تنظیم کرده‌اید وارد کنید.
3. «اتصال به پنل» را بزنید.
4. وضعیت ذخیره‌سازی باید `متصل به GitHub` را نشان دهد.
5. سند را ثبت کنید. سند جدید به‌صورت پیش‌فرض «در انتظار تأیید» است؛ پس از بررسی رسمی، آن را تأیید و معتبر کنید.
6. پس از ثبت، همان سند باید در فهرست منابع پنل دیده شود و موتور پاسخ‌گویی از همان `data/documents.json` بخواند.

## مسیرهای برنامه

- `/` گفت‌وگوی فارسی
- `/admin-ec-9842` پنل مدیریت
- `/hami` پیش‌نویس ارجاع به کارشناس
- `POST /api/chat` پاسخ‌گویی و بازیابی منابع
- `GET/POST/DELETE /api/documents` مدیریت منابع (نیازمند `x-admin-key`)
- `POST /api/setup-bale` تنظیم وب‌هوک (نیازمند `x-admin-key`)
- `POST /api/bale` وب‌هوک ربات بله

## محدودیت‌های مهم پیش از استفاده سازمانی

- انتخاب «دانشجو/استاد/کارشناس/مدیر» در صفحه گفت‌وگو در این نسخه احراز هویت واقعی نیست. تا زمان اضافه‌کردن ورود امن و کنترل دسترسی مبتنی بر نقش، **فقط اسناد عمومی و غیرمحرمانه** را وارد کنید. نقش انتخاب‌شده نباید به‌عنوان مجوز دیدن اطلاعات محرمانه تلقی شود.
- این نسخه جست‌وجوی واژگانی فارسی و بازیابی منابع را تقویت می‌کند، اما جایگزین ارزیابی کارشناسی، تحلیل حقوقی یا اعتبارسنجی رسمی بخشنامه نیست.
- صفحه حامی متن آماده ارجاع و امکان کپی/بازکردن ایمیل را فراهم می‌کند؛ ارسال خودکار ایمیل و ثبت گردش‌کار کارشناسی هنوز پیاده‌سازی نشده است.
- فایل‌های PDF و DOCX باید پیش از ورود به این نسخه به متن قابل جست‌وجو تبدیل شوند و متن استخراج‌شده به‌عنوان سند ثبت شود. OCR و پردازش خودکار فایل در این نسخه فعال نیست.
- توکن GitHub برای نمونه اولیه و حجم کم مناسب است؛ برای بار عملیاتی گسترده و ویرایش هم‌زمان چند مدیر، پایگاه داده تراکنشی مانند PostgreSQL توصیه می‌شود.

## استقرار

محتویات مخزن را روی شاخه متصل به Vercel بارگذاری کنید. Vercel به‌صورت خودکار Deploy می‌کند. پس از استقرار، ابتدا پنل مدیر را با کلید مدیریت باز کنید و بررسی کنید وضعیت ذخیره‌سازی GitHub باشد. پیش از افزودن اسناد واقعی، یک سند آزمایشی غیرمحرمانه ثبت کنید، سپس آن را از صفحه گفت‌وگو جست‌وجو کنید.
