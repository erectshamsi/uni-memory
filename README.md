# حافظهٔ سازمانی دانشگاه — Vercel

پروژهٔ استاتیک HTML/JavaScript با توابع Node.js serverless، بدون مرحلهٔ build. با واردکردن پوشه/محتویات مخزن در GitHub و انتخاب Vercel به‌عنوان پروژهٔ جدید قابل استقرار است؛ فرمان build نیاز نیست.

## راه‌اندازی
1. پروژه را در GitHub قرار دهید و در Vercel ایمپورت کنید.
2. در Project Settings → Environment Variables، `APP_URL` را با URL نهایی HTTPS تنظیم کنید.
3. اختیاری: `OPENROUTER_API_KEY` و `OPENROUTER_MODEL` (پیش‌فرض: `qwen/qwen-2.5-72b-instruct:free`) را تنظیم کنید. کلید را فقط در Vercel نگه دارید، هرگز در مرورگر/گیت قرار ندهید.
4. برای ذخیرهٔ پایدار مدیریت اسناد، یک توکن GitHub محدود به محتویات همان مخزن بسازید و `GITHUB_TOKEN` و `GITHUB_REPO` به‌شکل `owner/repo` را در Vercel تنظیم کنید. API سند، محتوای `data/documents.json` را commit می‌کند. پس از افزودن متغیرها، redeploy کنید.
5. برای ربات، `BALE_BOT_TOKEN` و اختیاری `BALE_WEBHOOK_SECRET` را تنظیم و redeploy کنید. `APP_URL` باید URL ریشهٔ عمومی پروژه باشد. سپس `/api/setup-bale` را یک‌بار باز کنید.

## وضعیت امنیت/پایداری (مهم)
- هیچ احراز هویتی در این نمونه وجود ندارد؛ API مدیریت اسناد، setup webhook و صفحهٔ مدیریت عمومی‌اند. قبل از استفادهٔ عملیاتی دانشگاه، احراز هویت و کنترل دسترسی اضافه کنید یا این endpointها را با محدودیت دسترسی شبکه‌ای محافظت کنید. دادهٔ محرمانه بارگذاری نکنید.
- Vercel filesystem موقتی است. بدون GitHub storage، تغییرات Admin قابل اتکا نیستند و ممکن است با اجرای سرد/استقرار تازه از بین بروند. در نبود اتصال، از Export JSON استفاده کنید و فایل را در مخزن جایگزین کنید.
- سه سند اولیه صرفاً متن‌های نمایشی، `pending` و نامعتبرند؛ هیچ‌یک از بخشنامه‌های واقعی کاربر در ورودی ارائه نشده بود. مدیر باید فقط نسخهٔ رسمی را وارد کند و پس از راستی‌آزمایی `approved` و `valid` کند.
- برنامه PDF و DOCX را در مرورگر با CDN استخراج می‌کند (نیازمند اینترنت و پذیرش CDN). TXT مستقل است؛ اگر کتابخانهٔ PDF/DOCX در دسترس نبود، متن TXT را وارد کنید. هیچ فایل خامی به API ارسال نمی‌شود.
- تشخیص پرسش تفسیری محافظه‌کار است اما هوش مصنوعی و تطبیق واژه تضمین کامل ندارند؛ هرگونه نظر تحلیلی باید به کارشناس ارجاع شود. پاسخ مدل جای مقرره یا نظر حقوقی رسمی نیست.
- آدرس حامی برای مرور وب: `https://mail.iau.ac.ir`. صفحهٔ Hami متن پیشنهادی می‌سازد؛ ارسال خودکار ایمیل یا صندوق مقصد رسمی پیکربندی نشده است. `mailto:` عمداً مقصد ساختگی ندارد.
- endpoint ثبت وب‌هوک فقط GET است و باید پس از تنظیم محرمانهٔ بات اجرا شود. اطلاعات secrets را داخل مخزن یا درخواست‌های سمت کاربر قرار ندهید.

## مسیرها
- `/` گفتگوی فارسی، `/admin` مدیریت منابع، `/hami` ارجاع کارشناس.
- `POST /api/chat` با `{ "question":"...", "role":"دانشجو" }`.
- `GET /api/documents`; `POST /api/documents` برای افزودن/حذف و `action: export`.
- `/api/bale` وب‌هوک؛ `/api/setup-bale` تنظیم وب‌هوک.

## نشر
`vercel.json` بازنویسی مسیرهای UI را تنظیم می‌کند. package manager/dependency install و build command ویژه لازم نیست. پس از deploy، APIها و صفحهٔ آغاز را در Deployment URL بررسی کنید. اجرای محلی اختیاری با Vercel CLI: `vercel dev`.
